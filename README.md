# Algorithmic Methods of Data Mining - Homework 1

This repository contains my solutions for **Homework 1** of the *Algorithmic Methods of Data Mining* course for Bahar Asadi.

The homework exercises were completed on HackerRank and cover Python fundamentals as well as several algorithmic programming exercises.

## Repository structure

```text
.
├── README.md
├── scripts.py
├── hackerrank-submissions.pdf
└── printouts/
    ├── screenshot-01.png
    ├── screenshot-02.png
    └── ...
```

### `scripts.py`

Contains the Python code for the exercises I completed. Each exercise is clearly separated and labelled with the name/path of the original challenge solution.


### `hackerrank-submissions.pdf`

A PDF printout of my HackerRank submissions page, included as evidence of the completed exercises.

### `printouts/`

Contains screenshots showing the successful HackerRank submissions/exercises.

## Notes

The solutions in this repository were written for the HackerRank exercises assigned in Homework 1. Since individual HackerRank challenges use their own input/output format, the sections inside `scripts.py` are intended to document the submitted solutions rather than to be executed together as one single program.
